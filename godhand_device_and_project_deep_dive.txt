6. ROOT CAUSE ANALYSIS: WHY 6-8 FPS IN-GAME ON HELIO G25
================================================================================
The in-game collapse is caused by three compounding CPU microarchitectural factors:

1. THE IN-ORDER PIPELINE LIMITATION (ARM CORTEX-A53):
   - The Cortex-A53 is an in-order execution processor with a simple 8-stage pipeline.
   - It cannot reorder independent instructions around a memory load or float stall.
   - Every single recompiled PS2 memory access reads or writes through the 32 MB RDRAM
     base pointer (`rdram[addr]`).
   - On out-of-order cores (Cortex-A78 / Snapdragon 8 Gen 2), speculative execution
     hides L1/L2 cache misses completely.
   - On Cortex-A53, every L2 cache miss stalls the execution pipeline for 40–80 clock cycles.

2. VECTOR UNIT 1 (VU1) INTERPRETER & AOT COVERAGE:
   - In 3D combat, God Hand executes heavy VU1 microprograms for:
     * Skeletal skinning matrix transformation (Gene's multi-joint martial arts model).
     * Directional lighting and specularity calculation.
     * Viewport frustum polygon clipping (`ps2_vu1_clip.inl`).
   - If a VU1 microprogram is not matched in the AOT fast-block cache, it falls back
     to `VU1Interpreter::executeMicroprogram`.
   - The interpreter executes instruction-by-instruction, decoding opcode fields,
     calling software float normalization routines, and writing back SIMD registers.
   - On Cortex-A53 @ 2.0 GHz, executing 100,000 interpreted VU instructions per frame
     takes >100 ms of pure CPU time.

3. GOVERNOR DOWNSCALING & SELINUX THREAD SHUFFLE:
   - Because `su` was not found at standard execution paths, CPU governors remained at `schedutil`.
   - Under continuous load from all 8 threads, the Linux CFS scheduler sees 100% core usage
     and attempts to balance thermal load by downclocking Cores 0–3 from 2001 MHz to 1200 MHz.
   - At 1200 MHz, the in-order Cortex-A53 single-thread performance is cut by another 40%,
     firmly clamping gameplay to 6–8 FPS.
